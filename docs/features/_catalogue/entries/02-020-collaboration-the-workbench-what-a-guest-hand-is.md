| Collaboration | **The workbench — what a guest hand is taught, and what refuses it** (`bin/collab/kit/.agents/skills/smidr-the-workbench/` · `bin/collab/kit/scripts/gates/referee-guard.sh` · `bin/collab/kit/scripts/gates/new-module-test.sh` · [how-to](docs/features/the-workbench-for-a-guest-hand.md)) | The collaboration kit standardised a repository's *files* and had nothing to say about its *hands*. Two faults a review kept catching too late became two refusals and one skill: a change to a gate, a hook or a ward must carry a fix note **and** name it in the message (a gate quietly weakened looks exactly like a gate that passes), and a new module with no test naming it is refused unless `.module-test.allow` says why (an 80-line interpreter landed in a host with every ward green, because reachability is not behaviour). The skill — *Smíðr*, the craft taught at the bench — carries the six steps of a slice, the five things never changed quietly, and a table of what each refusal means, so a contributor's agent reads the discipline once instead of learning it one review at a time. And `standardise.sh --check` now probes for **dead gates**, because this kit itself shipped a hook whose fix-note check sat after an `exit 0` and never ran | [docs/fixes/collab/2026-11-06-the-kit-had-a-gate-that-never-ran.md](docs/fixes/collab/2026-11-06-the-kit-had-a-gate-that-never-ran.md) |
