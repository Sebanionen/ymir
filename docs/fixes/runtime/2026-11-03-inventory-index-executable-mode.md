# Inventory executable modes come from Git, not the host

Windows reports ordinary tracked files as executable through os.access(X_OK); the inventory therefore classified data and README files as tools. The generator now reads NUL-delimited Git index metadata and treats only mode 100755 as executable. This also preserves spaces, tabs and newlines in tracked paths instead of splitting filenames on whitespace. Explicit relative POSIX path sorting avoids host-dependent Path ordering.

A regression invokes the real generator in a small temporary Git repository. It verifies indexed executable and data modes while working-tree permissions are inverted, complete output stability after another inversion, filenames containing whitespace, and mixed-case ordering. It passed on native Windows and WSL Linux. Shell syntax and diff whitespace checks passed. Full public registers are intentionally regenerated by the integrating branches after their source changes are staged.

The generator writes explicit UTF-8 with LF newlines on every host. The real-generator regression asserts LF output on Windows and Linux. Previously generated register data was retained exactly, with Git text normalization changing CRLF to LF only.
